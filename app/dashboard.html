How to read this page. Replay evaluations use controlled reference fixtures. Live framework scores are emitted only when an evaluator actually runs; currently, RAGAS is an opt-in EvidenceFlow integration. QuoteSense and FlowPilot report deterministic product/runtime checks. DeepEval, TruLens and Phoenix can be imported by the harness, but are not currently connected as live runtime emitters. Empty results are not zero scores. The comparison view shows signed metric movement, not an automatic quality verdict.
